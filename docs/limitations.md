# Limitations

This project is a local research system and has several important limitations.

- The embedding model and NLI model are local and may not always match specialized domain performance.
- The credibility heuristic is project-defined and should not be interpreted as objective truth.
- Contradiction detection is model-dependent and may fail on subtle paraphrases or domain-specific wording.
- The synthetic evaluation dataset is controlled and intended for reproducible experiments, not for broad real-world claims.
- Ollama availability is required for generation and may be absent on some machines.
- The project measures what it can execute in the local environment and does not claim results beyond those executions.
